## 1. 产品概述

### 1.1 产品定位

龙虾云是一个**自媒体自动化运营平台**，为小微企业主、个体户、副业人群提供全自动的小红书代运营服务。

**核心理念**: 用户"雇佣"一只小龙虾作为"自媒体员工"，通过对话交流告诉它要做什么，小龙虾学习老板的喜好，越用越懂你。

用户付费订阅后，小龙虾会自动：
- 理解用户需求（对话式配置）
- 学习用户偏好（记忆 + 优化）
- 按用户要求搜索/创作/发布
- 向老板汇报工作（发布记录 + 数据）

### 1.2 核心价值

| 用户痛点 | 龙虾云解决方案 |
|----------|----------------|
| 没时间做内容 | 全自动生成 + 发布 |
| 不会写文案 | AI 智能创作 |
| 不会做图 | AI 自动生成配图 |
| 不懂运营 | 内置爆款公式 |
| 怕封号 | 用户自带账号，安全可控 |

### 1.3 产品愿景

**短期**（MVP）: 验证商业模式，10 个种子用户付费  
**中期**（6 个月）: 100+ 付费用户，支持多平台  
**长期**（2 年）: 成为自媒体自动化第一平台

## 2. 目标用户

### 2.1 用户画像

| 类型 | 特征 | 需求 | 付费意愿 |
|------|------|------|----------|
| **小微企业主** | 有公司，没精力做内容 | 品牌曝光、获客 | 高（299 元/月） |
| **个体户/实体店** | 想获客但不会自媒体 | 引流到店 | 中（199 元/月） |
| **副业人群** | 想搞副业但没时间 | 被动收入 | 低（99 元/月） |

### 2.2 使用场景

**场景 1**: 餐饮店老板
- 开了一家火锅店
- 想通过小红书获客
- 但不会写文案、不会拍照
- → 订阅龙虾云，自动发布探店内容

**场景 2**: 美妆代购
- 做微商代购
- 想扩大客源
- 但每天发朋友圈效果差
- → 订阅龙虾云，自动发布美妆笔记

**场景 3**: 副业创业者
- 上班族，想搞副业
- 听说小红书能变现
- 但没时间运营
- → 订阅龙虾云，自动养号
